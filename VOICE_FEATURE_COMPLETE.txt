=== HOW TO USE ===

1. Open extension popup
2. Login/signup
3. Click the microphone button (🎤) next to send button
4. Allow microphone access (first time only)
5. Speak your claim or question
6. Click mic again to stop
7. System automatically:
   - Transcribes audio using Whisper API
   - Detects if it's a claim or question
   - If CLAIM: auto-sends for fact-checking
   - If QUESTION: lets you review/edit first

Backend:
- Audio routes in backend/app/routes/audio_routes.py
- Transcription in backend/app/analysis/audio_transcription.py
- Smart claim detection with regex patterns
- Supports Whisper API (primary)
- Max file size: 25MB
- Supported formats: webm, mp4, mp3, wav, ogg, m4a

Claim Detection Algorithm:
- Checks for factual verbs (is/are/was/were)
- Detects numbers and statistics
- Identifies absolute claims (always/never)
- Recognizes causation (causes/leads to)
- Spots controversial topics (vaccine/covid/election)
- Filters out questions and greetings
- Score-based system (2+ indicators = claim)
